## Проверки, выполненные в этом checkout

Дата: 2026-10-08.

- `node --check /tmp/binder-ui-check.js` — синтаксис JavaScript из `ui.html` проверен.
- HTML-проверка через Python `html.parser` — 117 уникальных `id`, все 186 литеральных `getElementById` разрешаются, теги `<body>` сбалансированы.
- Статическая проверка протокола — все 34 семейства исходящих UI-сообщений сопоставлены с обработчиками AHK; отдельно сверены позиции полей `save_bind`, `save_settings` и строк screenshot rules.
- `git diff --check` — проверка пробелов/концов строк.
- Статически подтверждено, что launch telemetry отсутствует в новых runtime-модулях. Старый небезопасный `SendLaunchStats` оставлен только в legacy-файле и не подключается.
- В репозитории `doctor_config.ini` — UTF-16LE, 38 секций слотов; `doctor_filters.ini` в checkout отсутствует. Код чтения использует `IniRead`, а отсутствующий файл фильтров не считается существующей пользовательской конфигурацией.

## Не проверено в этом окружении

Компилятор AutoHotkey v2 и Wine недоступны, поэтому **AHK compile/runtime не запускался**. Проверки ниже — обязательный ручной smoke-test на Windows с установленным AutoHotkey v2 и WebView2; они не отмечены как пройденные.

## Windows smoke-test checklist

Перед тестом сделайте копии `doctor_config.ini` и, если есть, `doctor_filters.ini`.

- [ ] Запуск с существующим UTF-16LE config: проверить загрузку всех 38 занятых слотов и оставшихся свободных слотов до 100; профиль, статистика, хоткеи и задержки отображаются без потери данных.
- [ ] Закрыть и открыть редактор существующего bind/ACI bind с неизвестной категорией: исходная категория и statType должны остаться выбранными; изменить одну строку и сохранить.
- [ ] Создать бинд в свободном слоте, добавить/переставить/дублировать/удалить строки, использовать быстрые вставки, индивидуальные и общие задержки, Undo и «Откатить всё»; проверить Ctrl+S/Ctrl+Z/Ctrl+D/Ctrl+Enter.
- [ ] Захватить обычную клавишу, модификаторную комбинацию, кнопку мыши и колесо; проверить Escape, timeout, повторный запуск/закрытие редактора во время захвата и отсутствие выполнения bind/system hotkeys во время захвата.
- [ ] Проверить занятый пользовательский хоткей: отменить замену и подтвердить замену; проверить блокировку системного хоткея, chat key и SC029, включая попытку конфликтной настройки через Settings.
- [ ] Запустить многосрочный bind в активной GTA; проверить подстановки `{P}`, `{MY}`, `{HOSPITAL}`, `{RANK}`, `{SPECIALTY}`, пользовательской переменной, задержки, jitter, статистики и восстановление буфера обмена.
- [ ] Во время длинной отправки нажать «Стоп» и configured stop hotkey; проверить прекращение следующей строки, снятие BlockInput/модификаторов и отсутствие зависших клавиш.
- [ ] Проверить отправку с закрытой GTA, при потере фокуса и с включённой/выключенной настройкой «только активное окно GTA»; текст не должен попадать в постороннее окно.
- [ ] Открыть игровой чат и попробовать запуск bind; проверить блокировку до Enter/Escape. Изменить chat key, применить настройки и повторить.
- [ ] Проверить set/clear/formats ID в главном окне и full/mini Overlay; проверить полный Overlay: навигация, страницы, запуск, P/C; mini Overlay не должен перехватывать клавиши списка.
- [ ] Проверить Radial Menu удержанием системной клавиши и четыре назначения; убедиться, что выбор запускается только после отпускания, а при потере GTA меню закрывается безопасно.
- [ ] Проверить локальный chatlog: SMS-номер/reply, упоминание, ключевые слова; при auto screenshot — совпадение phrase, активная GTA, создание F8-скриншота и перенос в датированную папку.
- [ ] Сохранить профиль/переменные/фильтр/настройки через «Сохранить», перезапустить и проверить round-trip; проверить custom filter `empty=true` и составные условия.
- [ ] Проверить INI/ACI import, compatible INI export, backup restore и запуск с отсутствующим/повреждённым config; перед проверкой восстановления сохранить отдельную копию пользовательских файлов.
- [ ] Проверить запуск/выход через tray, prompt несохранённых изменений, отображение clock/status и переключение binder.
