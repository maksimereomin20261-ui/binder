Экспорт и импорт

Экспорт сохраняет всё в один файл: профиль, бинды, категории, переменные, настройки Overlay и статистику.

При импорте текущий конфиг будет сохранён в песочницу config/_import_sandbox_*, приложение перезапустится.

Переменные

Используйте их в текстах биндов — значения подставятся автоматически:

{T}ID цели (собеседника)
{MY}Ваш ник
{ORG}Организация / фракция
{RANK}Ранг / должность

Пример: «Привет, {T}! Я {MY} из {ORG}, {RANK}. Чем помочь?»
